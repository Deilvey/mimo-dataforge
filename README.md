# MiMo DataForge

AI-powered data transformation and preprocessing platform built with Hermes Agent, Claude Code, and Cursor.

## Features

- Automated data cleaning and preprocessing
- Missing value imputation with ML-based strategies
- Outlier detection and handling
- Feature engineering and transformation
- Data quality scoring and validation
- Batch processing for large datasets
- CSV, JSON, Excel format support
- Real-time data pipeline integration

## Tech Stack

- **AI Engine:** MiMo v2.5-pro
- **Backend:** Node.js, Python
- **Frontend:** React
- **Database:** PostgreSQL
- **Container:** Docker

## Quick Start

```bash
npm install
npm run build
npm start
```
